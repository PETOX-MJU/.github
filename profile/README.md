# 펫톡스 (peTox)

나만의 반려동물 캐릭터와 함께하는 숏폼 디톡스 서비스

숏폼 앱을 설정한 기준 이상 사용하면 등록해 둔 반려동물 캐릭터가 화면 위에 나타나 시청을 방해합니다. 강제 차단이 아니라 캐릭터에 대한 애착을 이용한 개입으로, 사용자가 스스로 화면에서 벗어나도록 유도합니다.
